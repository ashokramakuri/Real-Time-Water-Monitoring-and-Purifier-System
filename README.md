# Real-Time-Water-Monitoring-and-Purifier-System
IoT-based water purifier &amp; quality monitoring

Developed as a Community Service Project, this system focuses on providing clean water using a natural sediment filtration method. Muddy water is filtered through multiple natural layers to remove impurities in real time. The project provides a simple, low-cost, and eco-friendly water purification solution for rural and underserved communities.
